# Recomp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Recomp to the Haltewekker iPhone app: a morning weigh-in with a weekly average, protein counted in household units, five daily habits, a weekly check, and one line on the ride home.

**Architecture:** All rules live in Foundation-only files (`RecompModel.swift`, `RecompMath.swift`, `RecompCheck.swift`, `OpenFoodFacts.swift`, `RecompStore.swift`). A new hostless XCTest bundle compiles those files directly and runs in CI on a simulator. The SwiftUI screens (`RecompScreen.swift`, `RecompScan.swift`, `RecompSettings.swift`, `RecompBits.swift`) read one `RecompStore.shared` and follow the Outfit pattern: a tag on the map, a card in the "more" panel, and a sheet.

**Tech Stack:** Swift 5, SwiftUI, iOS 17, VisionKit `DataScannerViewController`, XcodeGen, GitHub Actions (macos-15, Xcode 26), Open Food Facts API v2.

**Spec:** `docs/superpowers/specs/2026-11-15-recomp-design.md` (in Dutch; read it before starting.)

## Global Constraints

- iOS 17.0 deployment target, SwiftUI, no third-party packages.
- **No HealthKit and no new entitlements.** Sideloadly signing with a free Apple ID must keep working.
- UI copy is **English**. Food names may stay Dutch ("Kwark").
- Protein is never entered in grams for the fixed sources. Grams appear only as a small "≈ 20 g" readout and as "105 of 160 g".
- A day runs **04:00 to 04:00** local time. Weeks run **Monday to Sunday**.
- Daily goal defaults to **160 g**. **At most 7 sources** plus the Scan tile (8 tiles). **At most 5 habits.**
- Weight is accepted with comma or dot, in **30–300 kg**. Waist in **40–200 cm**.
- Look: the existing Paper style (`Paper`, `HWFont`, `BoardInk.sans`, `.paperCard()`, `PaperFill`, `.brass(pal, pad:)`), **one accent colour** `RecompStyle.accent = Paper.green`, `.monospacedDigit()` on every number, tap targets ≥ 44 pt, animations ≤ 300 ms, no badges, no notifications, no red crosses or streaks.
- `RecompModel.swift`, `RecompMath.swift`, `RecompCheck.swift`, `OpenFoodFacts.swift` and `RecompStore.swift` import only `Foundation` (and `Combine` for the store). They may not reference app types such as `Fmt` or `Paper`, because the test bundle compiles them alone.
- **No local Swift toolchain.** This container is Linux. Every build and test runs in CI. Because of that, each task writes its tests and code together and verifies them with one push, instead of a separate red run.
- Every push to `main` replaces the `latest-ios` release that the user installs. Work stays on branch `claude/cool-mendel-odsmk9`. Releases are published only from `main`.
- Persist to `UserDefaults.standard` under key `"recomp.v1"` as JSON.

## Review Focus

1. **Typed weight with a unit or stray characters** ("88,4 kg", "88.", " 92cm "): accept it. "8,8,8" and "abc" are refused quietly. Test in Task 2.
2. **The 03:59 / 04:00 boundary on a DST night** (Europe/Amsterdam, 29 Mar 2026 and 25 Oct 2026): an entry at 03:59 belongs to the previous day, including on those nights. Test in Task 1.
3. **Open Food Facts quirks:** `product_quantity` as a string ("500") or a number, quantity in kg or l, missing `proteins_100g`, `status: 0`. Expected: the right protein per pack, or "type it from the label". Test in Task 4.
4. **Gaps in weigh-ins** (the first weeks, a holiday, weeks with fewer than 4 weigh-ins): the check says "not enough weigh-ins" and never gives advice from thin data. Test in Task 3.
5. **Editing or deleting a source after logging it today:** today's entries keep their grams, because each entry stores its own grams per unit. Test in Task 5.

  ```swift
  struct Measure: Codable, Equatable { var day: DayKey; var value: Double }
  enum AdviceKind: String, Codable { case eatLess, eatMore }
  struct PendingAdvice: Codable, Equatable { var kind: AdviceKind; var shownOn: DayKey }   // shownOn is a Monday
  struct CheckState: Codable, Equatable { var pending: PendingAdvice? = nil; var baseline: DayKey? = nil }
  enum Verdict: Equatable {
      case notEnoughData
      case onTrack(kgPerWeek: Double)          // negative = losing
      case recompWorking(waistCm: Double)      // negative
      case eatLess, eatMore
      case waiting(adjustedOn: DayKey, nextCheck: DayKey)
  }
  enum WeightMath {
      static func weekAverage(_ w: [Measure], endingOn day: DayKey) -> Double?   // mean of days day−6...day; nil if none
      static func weekChange(_ w: [Measure], on day: DayKey) -> Double?         // weekAverage(day) − weekAverage(day−7)
      static func waistDue(_ waists: [Measure], skippedOn: DayKey?, today: DayKey) -> Bool  // none, or last ≥ 14 days ago; false if skippedOn == today
      static func waistSummary(_ waists: [Measure]) -> (latest: Double, sinceFirst: Double, firstDay: DayKey)?  // nil with fewer than 1
  }
  enum WeeklyCheck {
      static func evaluate(weights: [Measure], waists: [Measure], state: CheckState, today: DayKey) -> (Verdict, CheckState)
      static func adjusted(_ state: CheckState) -> CheckState      // baseline = pending.shownOn; pending = nil (no-op without pending)
      static func text(_ v: Verdict) -> (title: String, detail: String?)
  }
  ```
